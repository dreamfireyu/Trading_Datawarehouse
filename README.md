# Trading_Datawarehouse

This project is a data warehouse solution for a trading system that collects and manages stock market data from various sources. It uses Python, PostgreSQL, and open-source APIs to perform data extraction, transformation, and loading (ETL) processes, and provides a scalable and reliable data storage for trading strategy analysis and optimization.

# Features
·Constellation data warehouse design with fact and dimension tables

·Data collection from multiple market sources using open-source APIs

·Data transformation and validation using Python and ETL tools

·Data loading and update using PostgreSQL database

·Data quality and integrity checks using SQL queries
